Live browser server

Connect Manus

Manus runs tasks asynchronously. The workbench reaches it through a small proxy, because the Manus API refuses browser calls from any origin but its own.

Run server/manus_proxy.py and put its address here. The proxy holds the API key, so it never reaches this page.
Sent as x-mp-token. Leave empty if the proxy is open.
Create one at manus.im → Settings → Developers. Kept in this browser only and forwarded per request.
Why a proxy: api.manus.ai answers the CORS preflight with access-control-allow-origin only for manus.im. Because the key must travel in x-manus-api-key, every call is preflighted — so a page on any other origin is blocked before the request is sent.
